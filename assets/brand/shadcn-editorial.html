shadcnEditorial Brutalist

The full shadcn catalog, re-skinned in our design system.

Every component mapped onto shadcn's own token contract — --primary, --muted, --ring, --radius — using the flat eleven-colour palette, Manrope ExtraLight, hairline borders and blue as the single emphasis. This page is a theme preview; the token block at the top of the source is the drop-in theme.

!
No shadows, anywhere. The deck system forbids them, so overlays (dialog, popover, dropdown) separate with a hairline ring and a scrim instead of elevation. Black surfaces carry all chrome, which is where the accents fire hardest.
⚠
--destructive has no colour in this palette. There is no red. Destructive actions render as the heaviest neutral (black) with a blue inset marker. If delete actions must truly shout, add a semantic-only red token outside the palette — it is the one place the deck system can't serve a functional UI need.
